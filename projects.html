Amazon Review Sentiment Analysis

Large-Scale NLP Classification with PySpark

Built an end-to-end sentiment-classification workflow for Amazon customer reviews using distributed data processing and Spark ML.

  • Worked with 3.6 million training reviews and 400,000 testing reviews.
  • Cleaned text and prepared features using tokenisation, stop-word removal, HashingTF and TF-IDF.
  • Compared Linear SVC, Logistic Regression and Naive Bayes classification models.
  • Evaluated models using accuracy, ROC AUC, error rate and confusion matrices.
  • Achieved approximately 76.1% best recorded classification accuracy, with Linear SVC and Logistic Regression producing similar performance.
  • Demonstrates large-scale data processing, NLP feature engineering and comparative ML evaluation.

VitaBite

Personalised Vitamin-Focused Nutrition Assistant

VitaBite is designed for people who want to focus on a particular vitamin or micronutrient that matters to them, rather than displaying every nutrient at once.

  • Let users choose a specific vitamin or micronutrient to focus on, such as vitamin D, B12, vitamin C, folate or another supported nutrient.
  • Record foods, recipes, ingredient quantities and serving sizes to estimate how much of the selected nutrient is being consumed.
  • Calculate the contribution of each ingredient and combine those values into meal, serving, daily and weekly intake views.
  • Compare estimated dietary intake with appropriate nutritional reference values for the selected nutrient and user context.
  • Identify foods and recipes that are naturally rich in the nutrient the user wants to increase.
  • Allow users who already have a clinically measured result to record that information as context alongside their dietary tracking.
  • Keep clinical information separate from the nutrition calculation: the application supports dietary awareness and planning rather than diagnosing deficiency or calculating medical treatment.
  • Build a focused dashboard that changes when the user switches from one nutrient to another, making the experience personal rather than overwhelming.
